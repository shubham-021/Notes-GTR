## Suppressing Warnings

Rust is strict about unused code. If you declare a variable, import, or function and never use it, the compiler will warn you.

To suppress all unused-related warnings for an entire file or crate:

```rust
#![allow(unused)]
```

To suppress warnings for a specific function or variable:

```rust
#[allow(dead_code)]
fn unused_function() {}

#[allow(unused_variables)]
fn example() {
    let x = 10;
}
```

The difference between `#[...]` and `#![...]` is about scope:

- `#[...]` applies to the thing immediately after it
- `#![...]` applies to the enclosing item (the entire file or crate)

So `#![allow(unused)]` at the top of a file means "allow unused code for the entire crate/file," whereas `#[allow(dead_code)]` placed above a function means "allow this specific function to be unused."

Rust's preferred way when you intentionally don't use a variable is to prefix it with `_`:

```rust
let _x = 10;
let _unused_value = 20;
```

The compiler treats `_`-prefixed variables as intentionally unused and stays quiet about them.

## Hello World

```rust
fn main() {
    println!("Hello, world!");
}
```

`println!` is a macro (indicated by the `!`), not a regular function. It prints text to the console with a newline.
